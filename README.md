# 自由窗格 · dsh-free-pane

把 DeepSeekRuntime 的主区域变成一块**可以随便切的画布**：同一个窗口里并排放多个对话、网页、笔记、终端、文件夹和 Git 面板，位置、大小、比例都随你拖。

插件（bundle）形态发布：宿主半边跑在 DSH 进程里（本地反向代理 + 几个本地 RPC），界面半边跑在渲染层里（画布、分割、拖拽）。界面按 **Material 3** 做，配色走 **Material You** 动态取色——一颗种子色推出一整套颜色。

![概览：把对话、网页、终端、文件夹、文档放进同一块画布](<show/overview.png>)

## 它能做什么

- **从零开始的一块空画布**：没有固定网格。拖进来的第一件东西占满整块，第二件按鼠标靠近的那条边把第一块劈开——左、右、上、下都行，可以一直劈下去。
- **分隔条随便拖**：任意两个窗口之间的分隔条都能拖动改比例（13%–87%）。
- **窗口随便搬**：拖标题栏到另一个窗口的四条边上，就插到那一侧；拖到自己身上不动。
- **关掉就并回去**：点窗口右上角的 `×`，空出来的面积由邻居接管，不留洞。
- **万物皆可拖进来**：左侧会话列表拖一场对话、页面里拖一个链接、拖一个文件或目录、拖一段纯文字，落地就是对应类型的窗口。
- **右下角「添加」**：点一下弹出「添加卡片」，选一样就落进画布；想自己定位置就先加一张空卡片，再从卡片里挑内容。
- **布局会记住**：存在 `localStorage`（按 origin 分别保存），刷新、切标签后原样恢复。

## 随意摆放

拖标题栏换位置，拖分隔条换比例，四种方向都能劈。下面这张是同一块画布上七张卡片混排的样子：会话、浏览器、文档、图片、终端、笔记同时在跑。

![任意窗口随意摆放](<show/free-placement.png>)

## 多窗口并存

每张卡片都是一个独立窗口，各有自己的标题栏、缩放和关闭按钮。会话卡嵌的是真实的对话界面（宿主反向代理过来的），不是截图；终端卡在宿主进程里跑真正的 PowerShell。

![支持多窗口并存](<show/multi-window.png>)

## 三档比例尺

**75% 是设计基准**（不缩放）：最适合在一屏里塞下尽量多的内容。

| 档位 | 实际缩放 | 效果 |
| --- | --- | --- |
| 75% | 1× | 紧凑，一屏能放更多卡 |
| 100% | 4/3×（顶栏 48 / 正文 14 / 侧栏 320） | Material 3 的默认量级 |
| 125% | 5/3× | 大字、远距离看 |

缩放作用于整个窗格界面——顶栏、卡片、字体一起变，不是单独改字号。每张会话 / 面板 / 浏览器卡的头还可以再单独调内容缩放。

![三种比例尺对比](<show/zoom-levels.png>)

## 配色：一颗种子色

默认是 **DeepSeek 蓝 `#4D6BFE`**，也可以选「跟随宿主」让画布跟着 DSH 的强调色走，或者从一张图里取主色。明暗支持跟随 / 浅色 / 深色。整块画布的主色、容器色、描边、状态层都由这一颗种子推出来。

![不同配色下的同一块画布](<show/palettes.png>)

## 卡片种类

「+ 菜单」和空窗口选择器共用这 7 个基础种类；旧布局里的其它卡照常渲染，但不再出现在菜单里。

| 类型 | 说明 | 依赖 |
| --- | --- | --- |
| 会话 | 嵌入一场对话；重复卡排队 | 宿主反向代理 |
| 文件 | 目录树、文件标签、内嵌预览；Office 交给宿主文件面板 | 宿主 |
| 浏览器 | 多标签 + 地址栏 | 无 |
| 笔记 | Markdown 编辑 + 预览 | 无 |
| 终端 | 在宿主进程里跑 PowerShell 命令 | 宿主 |
| Git | 仓库发现、状态、暂存 / 提交 | 宿主 + git |
| 设置 | 明暗、配色、尺寸 | 无 |
| 填空窗格 | 先摆一个空盒子，再选内容 | 无 |

完整的「保留 / 合并 / 仅兼容」表见 [docs/card-kinds.md](docs/card-kinds.md)。

## 安装

```bash
# 桌面版：插件页 → 安装 bundle → 直接输入包名
dsh plugin add dsh-free-pane --profile desktop

# 或本地文件：插件页 → 安装本地 bundle → 选 tgz / 解压后的目录
dsh plugin add dsh-free-pane-0.10.20-alpha.1.tgz --profile desktop
```

装好后：左栏点「自由窗格」，或在右侧栏 `+ 新标签 → 自由窗格`。第一次是空画布，点右下角「添加」。

宿主侧有 RPC 变更，**装完要完全退出 DSH 再开**；只按 `Ctrl+R` 只换渲染层。

详细步骤见 [docs/install.md](docs/install.md)，兼容性边界见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 给 AI 的适配 skill

包里带一份 `skills/free-pane-plugin-adapter/SKILL.md`。它的作用是：当你想把**别的插件**（某个面板、某个路由、某个 widget）塞进自由窗格的卡片里时，让 AI 按现成的路子判断该用哪种桥——宿主 RPC、面板嵌入、页面 iframe，还是原生卡片。

装到本机 skill 目录即可命中：

```powershell
Copy-Item -Recurse ".\skills\free-pane-plugin-adapter" "$env:USERPROFILE\.dsh\skills\"
```

之后问它「把这个插件接到自由窗格里」，它会先分类surface、再选最小的桥，并在你机器上验证。

## 兼容性

- `engines.dsh: >=0.2.2-rc.5 <0.3.0`，在 DSH `0.2.2-rc.5` 上验证
- 兼容性回归脚本在 `compat/`，跑一遍会用一个干净的 profile 装上 tgz、起无头浏览器，检查启动、画布、菜单、缩放、宿主 RPC 和页面错误
