# 自由窗格 · 操作说明

## 这是什么

DSH 默认是一次看一场对话。自由窗格把主界面变成一块画布：**对话和工具都可以作为卡片摆在同一个平面上**，并排、叠放、随手改大小，布局会记住。

它的判断标准只有一条：**你需要的两块东西，能不能在同一屏里同时看见、并且互相传递数据。**

## 它能给你什么

**多场对话并置。** 不同的会话可以同时开着，各自独立工作；每张会话卡片就是一份完整的对话界面，不是缩略图、不是转发。

**工具成为卡片。** 笔记、终端、文件树、浏览器、插件接口、OCR、上下文统计、会计读数……都可以独立成卡，摆在对话旁边而不是藏在侧栏里。

**把插件的某一块单独摘出来。** 这是它最有价值的能力：插件里一块有用的面板（余额、轮次与 token 读数、对话目录、用量趋势、活动卡片），可以只把那**一块**摘成卡片，而不必搬进整个插件页面。

**卡片之间可以有从属关系。** 一张计量卡可以「接上」某场对话，成为那场对话的仪表；它读的就是那场对话的数据，换一场对话就换一份读数。这种从属是显式的：接上了会写清楚接的是谁，断开也写清楚是独立状态。

**数据能往下走。** 抓到的读数、识别出来的文字，可以直接交给旁边的笔记卡片继续编辑——它负责取数，你负责判断。

**布局与外观可以调。** 有填充与自由两种排布方式；外观按 Material 3 做，配色是 Material You 动态取色——挑一颗种子色，整块画布（卡片、按钮、标签页、进度条）一起换，明暗单独选跟随/浅色/深色。界面元素（卡片、标题条、按钮、菜单、取点面板）共用同一套颜色角色、字号与圆角，不会各长一套。

**尺寸也能自己调。** 顶栏「⋯」→「开发者选项（尺寸）」把顶栏高度、卡片标题栏高度、标题字号、卡片圆角与间距、画布留白、卡头小按钮、顶栏图标按钮、卡片内工具条、输入框、FAB、侧边抽屉的宽度和圆角都做成滑杆，拖动即时生效并记住；嫌滑杆不好对准就直接输数字，另有紧凑/标准/宽松三档整套切换。调顺了就点「复制 CSS」，把 `.fp-canvas{--fp-head-h:44px;…}` 贴回 `client.js` 变成新默认值。

**浏览器在窗内。** 网页卡片是一个带标签页的小浏览器，搜索、跳转都留在这一格里，不外溢到系统浏览器。

## 它不做什么

- 不改变 DSH 本身的行为，关掉插件界面即恢复原样。
- 不去猜测、干预别的插件的实现；它只读取界面上已经存在的东西。
- 不虚构不存在的卡片：摘不出来就不摆出来，宁可少一项，也不给一个点了没反应的入口。
- 不负责模型能力，也不代替你判断内容对错。

## 你会遇到的几种状态

**卡片在排队。** 一份对话界面本身很重，所以同一时刻只让有限的几份真跑起来，其余的显示为待切换状态。这不是失败，是取舍。

**卡片一开始是空的。** 空卡片是让你指定它显示什么，不是加载失败。

**界面雾化并暂停。** 加入、拖拽、调整大小时会短暂冻结并加一层雾——这是刻意的：让变化中的版面不闪，也让误触不落进卡片内部。

**某块内容显示为静态快照。** 说明原来那块界面此刻不在屏上，显示的是抓取那一刻的样子，不会随原界面更新。

## 数据与边界

- 所有读数都来自本机已有的数据源，插件只读不写。
- 卡片的从属关系存在本机，重开界面后仍然成立。
- 它能嵌的网页受站点自身的安全策略限制：拒绝被嵌入的站点，不会因为放在这里就变得可嵌。
- 内部接口只对本机开放；外部页面无法借这块画布去调用本机能力。

## 一句话

**它不是另一个聊天界面，是一张能同时摆下「对话、工具、仪表」的桌面**——你怎么摆，它就怎么记。
